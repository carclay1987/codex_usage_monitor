# Codex Usage Audit

Read the supplied `usage-report.json`. Treat its values as aggregates; do not inspect raw Codex journals, conversation text, or project files.

Write the result in Russian for a user optimizing their own Codex workflow. Lead with the two or three changes likely to save the most usage. For each recommendation, connect a measured signal to an action and explain the expected direction of improvement. Separate exact measurements from estimates and avoid inventing token savings that the report cannot support.

Cover only signals present in the report: repeated context compactions, startup input, cache share, context pressure, tool output volume, request categories, and unusually costly tasks. Mention healthy signals briefly when they help prevent unnecessary optimization.

End with a short prioritized experiment for the next week containing no more than five steps and measurements the monitor can verify afterward.
